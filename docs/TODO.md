# Refdesk 开发清单

## 0.1 桌面版

- [x] 初始化 Rust 项目、Windows 构建和启动器。
- [x] Windows 本地运行日志，默认 INFO，支持后台写入、按日滚动和过期清理。
- [x] 仓库与 worktree 列表、子模块自动挂载与按需加载、会话恢复和后台日志预读。
- [x] 提交图、多父提交、分支及标签、历史搜索和两提交比较。
- [x] 分支浏览、切换和创建。
- [x] 分支和标签按 / 分层，支持目录整组勾选以及搜索展开。
- [x] 分支树与提交图显示上游及领先和落后数，同点时合并标签。
- [x] 提交详情、变更文件、暂存、取消暂存、提交、获取、快进拉取和推送。
- [x] 提交图右键检出、合并、摘取、创建分支和标签，以及工作树节点的提交、暂存全部和丢弃未暂存改动。
- [x] 统一 Git 写操作的完成反馈、局部确认和按范围校准。
- [x] 并排文本 diff、内置 Excel 单元格 diff。
- [x] 外部 diff 工具规则和 SmartGit 配置导入。
- [x] 工作台亮暗主题各两套，支持即时切换和会话恢复。
- [x] 用临时仓库验收图形、Git 数据和 Excel 工具。
- [x] 以 banshu 为当前仓库启动，登记四个工作树入口及 banshu/common。
- [x] 对照真实 banshu 的合并线和 origin/main 分支，交付分支复选与启动、切换计时。
