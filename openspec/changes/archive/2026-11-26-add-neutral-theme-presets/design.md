## Context

工作台通过共享色板绘制，外观菜单按主题 ID 分组，窗口边框和会话恢复也使用该 ID。

## Goals / Non-Goals

为两张参考图各提供一个可独立选择的配色预设，沿用 Refdesk 现有的工作台布局和交互。

## Decisions

- 浅灰蓝用白色提交区、浅灰工具栏和浅蓝选区。炭灰紫用炭灰工作区、灰色分隔线和蓝紫选区。辅助文字与 Git 状态色按 Refdesk 的选区、差异底色和列表背景调整对比度。
- 新增 `neutral-light` 和 `neutral-dark` 两个会话 ID，沿用主题注册、重绘和配置保存路径。既有 ID 和默认暖灰绿继续有效。

## Risks / Trade-offs

作者、日期、行号及 Git 状态可能落在选区或差异底色上。验收覆盖这些区域的对比度，以及亮暗主题的实际渲染。
