## Context

egui 从应用登记的字体字节绘制文字。Windows 已通过同一套字体定义为比例和等宽字体族提供中文回退。

## Decisions

- 通过 Core Text 的 `zh-Hans` 系统字体级联找到简体中文字体，由系统返回本机字体文件的 URL。苹方和其他系统中文字体可随 macOS 版本存放在不同目录。
- 使用 PostScript 名选择字体集合中的字面，并核对该字面能提供常用中文字符。系统级联没有返回可读字面时，通过 Core Text 查询苹方简体及可用的系统中文字体。
- 将选中的字体追加到 egui 的比例和等宽字体族，沿用两族现有主字体与共用的字形基线。

## Risks / Trade-offs

系统字体可能不可读取或采用渲染器不支持的格式。跳过不可用的字面并检查下一候选项，字体初始化仍可完成。
