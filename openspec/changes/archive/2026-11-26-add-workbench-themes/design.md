## Context

工作台通过 egui 样式、自绘窗格和 Win32 窗口边框三个入口使用颜色。提交图的数据已经保存轨道颜色索引，可在绘制时映射到当前预设。

## Goals

在一次重绘中为所有 Refdesk 控件选用相同主题，并沿用会话配置的读写边界。系统弹窗和外部工具由其所属应用管理外观。

## Decisions

- 用 `ThemeId` 表示四套内置预设，用 `Palette` 按用途定义颜色。预设包含 Git 状态色、增删差异的背景组合和八种轨道色。预设使用 Rust 常量，所有视图共享同一份定义。
- 启动读取配置后将主题应用到 egui 和 Windows。选择菜单项后，在本帧绘制结束时提交选择并请求重绘，使窗口、弹层和自绘内容在下一帧一起更新。
- 主题选择沿用既有原子会话写入。字段缺失或预设 ID 无法识别时回退暖灰绿，其他配置照常读取。
- Win32 边框在主题切换及窗口激活状态变化时取当前主题的边框色。标题栏的外观按钮与原有按钮一同参与命中测试。

## Risks / Trade-offs

亮色下细轨道、次级文字和差异填充的对比度容易不足，使用适合白底的预设色值，并在实际窗口内检查选中行、悬停态和高 DPI 下的表现。
