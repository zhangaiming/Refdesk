## Context

右侧文件列表由工作树与提交详情共用，并按可见行绘制。窗格可拖到 220 逻辑点宽。

## Goals

让目录信息与分组计数加入现有单行布局，缩写时优先保留能区分同名文件的目录段。

## Decisions

- 分组标题使用现有样式和行高。右侧数量与目录共用右边距。
- 状态符号、文件名及目录按文件名字体的基线绘制。组名与数量共用同一基线。
- 以 Git 相对路径拆分目录和文件名。根目录的目录列留空。目录用次级文字色，窄栏给它保留一段可用宽度，文件名较短时可以多显示目录。
- 目录放不下时，以同名文件共用的末尾目录段为依据，优先显示有区分作用的目录段。完整相对路径可通过悬停查看。
- 用隔离仓库与窄栏截图验证两个同名文件共享末级目录时的效果。
