## Context

文件和工作树节点操作共用 Git 写任务。原完成事件统一清除选区，并请求重载历史和完整工作树状态。

## Decisions

- 等待 Git 写操作成功再移动可确定的文件，更新分组和计数。两侧同时有变化、冲突、重命名或 Gitlink 等情况先对相关路径定向读取。定向读取失败时保留这些路径的显示，由完整 Git 状态校准。
- 索引写入结束时作废该工作树旧的状态请求。在本帧文件视图构建后排队读取状态，让临时分组有机会先绘制。结果仍按工作树和请求编号匹配。
- 索引更新不重读提交图。用户已经选中的受影响文件随分组移动，真实结果回来后按同一路径校准。用户已切到其他仓库或历史提交时，保留当前查看内容。

## Risks / Trade-offs

- 路径查询只读取相关文件。完整状态负责校准跨路径重命名、外部编辑和其他路径的改动。写入失败时保留原显示，由错误路径反馈并同步真实状态。
