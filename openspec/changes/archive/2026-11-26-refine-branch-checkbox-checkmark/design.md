## Context

分支树的 HEAD、目录和引用使用 egui 复选框，控件负责点击区域、焦点、主题方框和半选语义。

## Decisions

- 保留原有控件，使用两枚 SVG 替换方框内的选中与半选标记。通过与 egui 同版本的 SVG 加载器按显示尺寸读取内嵌资源，并按控件状态着色。
- C 款的路径和线宽直接取自用户选中的预览。半选图标沿用相同的圆头和 2.45/21 的线宽比例，放在方框中央。

## Risks / Trade-offs

- 覆盖标记时需保留原来的文字截断、点击命中和分组状态反馈。用 Windows 实际窗口复核空框、半选和选中三种显示，并验证分支筛选。
