## Context

工作台配色目前由固定主题 ID 解析。会话恢复、egui 控件和 Windows 窗框都通过该 ID 使用同一色板。

## Goals / Non-Goals

允许用户直接放入、编辑和移除主题文件。启动时统一加载主题，外观菜单继续即时切换已加载的主题。

## Decisions

- 从会话配置文件旁的 `themes` 目录加载一主题一 JSON。文件名去掉扩展名作为主题 ID，英文字母按小写匹配，JSON 提供名称、明暗模式和完整色板。
- 保留四套静态色板并保留其 ID。浅灰蓝和炭灰紫沿用原来的 ID，首次运行时将项目示例写到用户主题目录。写入使用不覆盖的持久化操作，完成后在会话目录记录安装状态，用户移除文件或目录后不会再次生成示例。
- 菜单底部始终可见「自定义主题...」。通过 Windows Shell 打开同一个主题目录，目录不存在时先创建。
- 会话保存主题 ID。启动时解析所选主题，egui 和 Windows 窗框使用解析后的配色。

## Risks / Trade-offs

单个主题文件损坏或与内置 ID 冲突时会跳过该文件。所选主题不可用时使用暖灰绿，并保留会话中的 ID，便于文件恢复后继续使用。
