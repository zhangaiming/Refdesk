## Why

图片变更目前只显示二进制文件大小或 Git LFS 指针，无法在差异窗格内看到实际改动。

## What Changes

- 在现有差异窗格并排显示旧图和新图，标注尺寸，用棋盘格衬托透明区域。
- 优先从本地 Git LFS 缓存读取对应版本。缓存未命中时后台下载所选对象，读取或解码失败时在该侧显示原因。
- 左右两侧独立加载，已就绪的图片先显示，待下载侧在原位显示加载状态。
- 选中文件时立即切换到对应差异视图并展示版本表头，后台只加载具体差异内容。
- 提供适应窗格与原始像素两种查看方式，原始像素下两侧可同步拖动。
