## ADDED Requirements

### Requirement: 先显示所选文件的差异视图

Refdesk SHALL 在选中文件时清除上一项差异内容，显示新文件对应的差异工具栏和版本表头，并在后台加载内容。

#### Scenario: 切换不同类型的文件

- **WHEN** 用户选择另一项文本、工作簿或图片变更
- **THEN** 差异窗格 SHALL 在解析完成前显示新文件的对应界面和加载状态，随后将该项内容填入当前视图

### Requirement: 并排预览图片版本

Refdesk SHALL 在差异窗格中并排显示 PNG、JPEG、BMP、GIF 和 WebP 的旧版和新版，标注版本和像素尺寸，以棋盘格衬托透明区域。动态图预览首帧。默认以相同比例适应窗格，并可切换到原始像素同步拖动两侧。

#### Scenario: 比较提交、暂存区或工作树图片

- **WHEN** 用户选择一项支持的图片变更
- **THEN** 客户端 SHALL 读取差异所选的左右快照并展示对应图片，保留长宽比

#### Scenario: 比较本地缓存中的 Git LFS 图片

- **WHEN** 所选快照包含 Git LFS 指针，且对应对象存在于本地缓存
- **THEN** 客户端 SHALL 显示该对象的实际图片，无需联网或检出文件

#### Scenario: 下载尚未缓存的 Git LFS 图片

- **WHEN** 所选快照的 Git LFS 图片尚未缓存，仓库的 LFS 设置允许下载
- **THEN** 客户端 SHALL 在后台请求该快照指针指定的对象，下载成功后显示该版本的实际图片，保留工作树和索引

#### Scenario: 一侧先完成预览

- **WHEN** 图片比较的一侧已就绪，另一侧仍在读取或下载
- **THEN** 客户端 SHALL 立即显示就绪侧，在另一侧显示「加载中」，并在该侧完成后原位显示图片或失败原因

#### Scenario: 下载时切换文件

- **WHEN** 用户在一侧图片加载期间选择其他文件或仓库
- **THEN** 客户端 SHALL 取消上一项下载，并忽略该项迟到的图片结果

#### Scenario: 只有一侧可预览

- **WHEN** 图片为单侧新增或删除，或者一侧的 LFS 对象下载失败或被跳过、图片无法解码或超过预览上限
- **THEN** 客户端 SHALL 在相应一侧显示原因，并继续展示另一侧可用图片
