## MODIFIED Requirements

### Requirement: 关键操作可按请求追踪

Refdesk MUST 记录应用启动与退出、配置错误、仓库添加与激活、图和状态首次显示、分支筛选绘制结果、Git 写操作以及差异失败。涉及工作树的异步事件 MUST 可按匿名工作树标识和请求编号关联。

#### Scenario: 仓库激活和后台任务

- **WHEN** 工作树激活并首次显示提交图和状态
- **THEN** 日志可关联激活、图就绪和状态就绪，并显示相对激活的耗时
- **AND** 读取失败或慢请求可从日志定位，DEBUG 级别补充缓存、队列、处理和过期结果的信息

#### Scenario: Git 操作和差异

- **WHEN** 用户实际发起 Git 写操作，或差异比较及外部工具启动失败
- **THEN** 日志包含受控的操作类型和结果，以及已知的耗时、错误分类或子进程退出码

#### Scenario: 提交图分页与缓存读回

- **WHEN** 提交图读取下一批历史、恢复缓存页或搜索已加载的记录
- **THEN** DEBUG 日志可关联历史快照和后台请求，并分别记录新增提交数、从磁盘读回的页数或匹配数

#### Scenario: 分支筛选就绪或被替换

- **WHEN** 用户改变分支筛选并等待新提交图，或在新图就绪前再次改变筛选
- **THEN** 运行日志 MUST 记录每个请求的绘制结果、等待耗时、最大绘制间隔、缺页帧数和过期结果数
- **AND** DEBUG 日志记录筛选模式和显式选中的引用数量，字段遵循受控日志约定
