## Context

提交图按行虚拟化。后台读取和缓存按工作树及请求编号隔离。

## Decisions

- 每次绘制滚动区后，根据实际滚动偏移和视口高度计算末尾剩余距离。距末尾 12 行以内时请求下一批，滚轮和滚动条共用同一触发条件。
- 每个历史快照按 Git 的 date order 单向读取，并把提交与计算好的轨道按页写入会话临时目录。轨道构建只保留待连接的父边和颜色，继续从已构建的页向后追加。
- 界面按绝对行号保留视口覆盖的页和前后相邻各一页。回滚后台读缓存，首次滚到末尾继续读取 Git。未激活的工作树只保留磁盘页和快照元数据。
- 搜索在后台查询同一快照的已加载页，可定位已换出的结果。刷新及切换范围时废弃旧请求，缺页或读取失败时显示状态并由刷新重试。
