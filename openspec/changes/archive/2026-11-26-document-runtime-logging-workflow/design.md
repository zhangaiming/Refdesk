## Context

README 供用户配置运行日志，OpenSpec 主规格定义日志行为。开发流程还需要把这些约定带入日志改动和验收。

## Goals / Non-Goals

在工作流中说明维护入口、字段约束和验收方式。运行日志行为以现有主规格为准。

## Decisions

- 以 README 和主规格分别维护配置方法和行为约定。工作流提供链接，并说明各自的更新条件。
- 在变更入口明确事件关联、字段脱敏和后台写入约束。日志功能使用隔离会话验收，启动和切换仍使用现有性能计时入口。

## Risks / Trade-offs

- 同一项默认值写在多处会产生偏差。工作流引用使用说明和主规格以减少重复维护。
