## Context

本机 SmartGit 24.1.5 的图形列通过本地日期格式化作者时间，调用链和偏好设置记录在 `docs/SMARTGIT_REFERENCE.md`。

## Decisions

- Git 历史记录同时读取作者时间戳和原有日期。时间戳用于提交图，原有日期继续供提交详情使用，也可在时间戳缺失时显示。
- 绘制提交图时按系统时区换算时间戳，以本地日历日计算日期差。使用「昨天」和「周一」至「周日」，在窗口空闲时定时重绘以反映日期切换。
- 扩展等宽数字列以容纳完整年月日和时分。表头和正文共用列边界，使用当前主题的文字色。悬停显示完整本地时间。
- 中文前缀用界面正文的比例字体单独排版，按同一行基线放在等宽时分左侧。这样数字的垂直位置和右边距由数字本身的字体度量决定。

## Risks / Trade-offs

完整时间占用更多横向空间。窄窗先隐藏 SHA 和作者，为时间和消息保留空间。
