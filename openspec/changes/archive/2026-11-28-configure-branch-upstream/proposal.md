## Why

Refdesk 可以展示已配置的跟踪分支。缺少上游时，普通推送可能在状态栏报错，用户需要切到终端配置。首次推送和调整跟踪目标时，用户需要在客户端里完成设置。

## What Changes

- 在本地分支的右键菜单提供设置跟踪分支的入口。
- 推送未配置跟踪分支的本地分支时，提供选择已有远端分支的引导和本次推送并建立同名跟踪分支的选项。

## Capabilities

### Modified Capabilities

- `git-operations` 增加跟踪分支设置及推送前的引导。

## Impact

涉及分支树、推送入口、共享弹窗及 Git 操作和引用刷新。
