## 配置路径

启动器沿用 EXE 的配置路径解析，通过移除批处理里的 `REFDESK_CONFIG` 设定，让系统用户目录成为两个入口的默认位置。调用方设定 `REFDESK_CONFIG` 时，启动器将该环境变量传给 EXE，便于验收使用隔离会话。

## 本机迁移

本机旧会话从项目 `.local/settings.json` 复制到 `%APPDATA%\Refdesk\settings.json`。在创建目标前核对仓库清单和活动仓库，使用同目录的临时文件写入并校验，再以禁止覆盖的方式发布。原文件作为备份。保留完整 JSON 可一并迁移分支选择和 Diff Tools 设置。

## 验收

清除验证进程中的显式配置路径，从启动器和相同的 EXE 依次启动。每次检查活动仓库的激活及提交图、工作树状态就绪，关闭后核对磁盘会话。另用临时路径启动两个入口，验证显式配置可用。
