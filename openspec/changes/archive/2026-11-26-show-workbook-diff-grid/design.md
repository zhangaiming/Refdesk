## Context

内置视图原来接收一份变化清单。展示完整的物理坐标需要在两侧提供所有已用单元格，并能跳到跨行列的变化位置。

## Goals / Non-Goals

旧、新工作表共享工作表选择、焦点坐标和滚动位置。两侧保留各自的值和公式。

## Decisions

- 解析进程返回按物理坐标排序的单元格。相同单元格只传一份显示内容，空白坐标由界面补齐。
- 网格共用滚动区域，只渲染可见单元格和固定表头。首个变化自动定位，导航按行列顺序移动。
- 使用 Refdesk 的色彩、字号和控件。窄视口使用同一组成方式。

## Risks / Trade-offs

- 完整工作表需要传输更多数据。解析响应按流读取，并保留进程和传输上限。
