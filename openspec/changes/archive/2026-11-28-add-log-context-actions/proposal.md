## Why

用户在查看历史时需要直接对右键点中的提交执行检出、合并、摘取或创建引用。提交图顶部的工作树节点也应提供当前改动的常用入口。

## What Changes

- 提交右键增加检出、合并、摘取、创建分支和标签，提供复制完整提交说明和完整 ID。
- 工作树节点右键提供打开提交编辑区、暂存全部和丢弃未暂存改动。
- 写操作显示目标，完成后刷新对应工作树的历史和状态。

## Capabilities

### Modified Capabilities

- `desktop-workbench` 的提交图右键命令。
- `git-operations` 对历史提交和当前工作树的写入行为。

## Impact

涉及提交图、操作确认、工作树提交编辑区和 Git 命令封装。
