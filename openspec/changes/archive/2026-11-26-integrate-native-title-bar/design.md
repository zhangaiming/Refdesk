## Context

eframe 0.31.1 创建 Win32 主窗口。egui 绘制工作台和标题栏按钮，Windows 的窗口样式和消息负责系统交互。

## Goals

- 把应用图标和 Git 操作放在暖灰色标题栏左侧，Diff 工具和窗口按钮放在右侧。
- 保留拖拽、双击、四边四角缩放、系统菜单及 Windows 贴靠。

## Decisions

- 通过主窗口句柄调整 Win32 客户区并保留标准窗口样式。egui 绘制窗口按钮，最大化和还原区域返回 `HTMAXBUTTON`，让 Windows 识别贴靠入口。
- 标题栏高 34 逻辑点。右侧三个窗口按钮各宽 46 逻辑点，并占满栏高。图标和应用按钮沿标题栏的水平中心线排列，24 逻辑点高的应用按钮上下各留 5 逻辑点。两组控件之间的空白用于拖拽，顶边空白仍响应缩放。当前仓库和分支在左侧导航区显示。
- 正常窗口用 DWM 细边框，最大化沿用系统有效工作区。安装窗口子类失败时使用标准窗口和工具栏。

## Risks / Trade-offs

- 贴靠、非客户区渲染和 DPI 坐标需要用 Release 产物实测。手动调整维持 930×610 逻辑点最小视口，系统贴靠可分配更窄的空间。
