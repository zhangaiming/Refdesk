## Context

内置比较使用 Git 快照对选中的文件取样。图片已使用可取消的 Git LFS 下载，Windows 工作簿解析运行在限制内存和 CPU 时间的子进程中。

## Decisions

- 每种格式接入类型化的加载、比较和渲染接口。注册项决定适用文件以及可选的原始文本入口。应用持有一个统一的会话接口。
- 后台在同一个调度请求中并行读取两侧并逐侧发布。比较使用已解析的内容，在两侧处理完成后发布。每次选择生成新的请求编号。公共会话使用专用接收端，验证所有分侧与比较结果的工作树标识和请求编号。切换时关闭旧接收端并取消后台工作。
- 公共窗格绘制版本表头、双栏边界和结构化状态。各格式在内容区管理工具栏和绘制，分栏共用当前会话的交互状态。
- 工作簿解析进程逐侧返回按坐标排序的内容，保留进程限制。解析结果在后台合并，用在同一工作表的差异网格中。

## Risks / Trade-offs

- 同一时间可能运行两个受限的工作簿解析进程。解析数量由当前比较请求的两侧限制，切换时通知进程退出。
- 工作表按名称保持用户已选的页面。没有手动选择时，比较完成后沿用原有的首个变化工作表定位。
