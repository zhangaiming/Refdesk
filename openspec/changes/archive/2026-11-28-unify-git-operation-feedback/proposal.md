## Why

Git 写操作目前各自决定完成后如何重读，暂存以外的操作会统一重载工作树和提交图。统一流程应先报告命令结果，再按可确认内容和受影响的数据范围刷新。

## What Changes

- 在现有 Git 写任务上统一成功反馈、局部更新、可选定向读取和完整校准。
- 接入索引操作、丢弃、创建引用、提交、摘取、检出、切换、合并、拉取、获取和推送。
- 让同工作树的后续操作接续未完成的校准，避免迟到结果覆盖新显示。

## Capabilities

### Modified Capabilities

- `git-operations` 的操作反馈、确认与刷新范围。

## Impact

涉及 Git 命令策略、工作树后台任务、仓库分支信息与提交图的 HEAD 显示。
